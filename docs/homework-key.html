Abstract

A worked answer to the Tidyverse homework. Using the mtcars data distributed with readr as a stand-in for a data set a student would find, we parse the file, derive fuel economy in metric units with mutate(), and summarize fuel use and power by cylinder count in a publication-quality table.

library( tidyverse )
library( knitr )
library( kableExtra )

This key uses mtcars.csv, which ships with the readr package, in place of a data set the student would go and find. readr_example() returns a path to the file on disk, so reading it models the “download it into your project folder” option. Any found data set meeting the assignment’s five conditions would be handled the same way.

Methods

Data. We used the 1974 Motor Trend road-test data distributed as mtcars.csv with the readr package (Henderson & Velleman 1981): 32 car models, each a row, with fuel economy (mpg), engine displacement, gross horsepower, weight, and number of cylinders (cyl), among other fields. We read the file and selected the four columns we needed, renaming as we went.

read_csv( readr_example( "mtcars.csv" ) ) |>
  select( Cylinders = cyl,
          MPG = mpg,
          Horsepower = hp,
          Weight = wt ) -> cars

Analysis. Fuel economy was recorded as miles per US gallon, which is awkward for a metric summary and, being a ratio, does not average sensibly. We used mutate() to convert it to litres per 100 km (235.215 / MPG); this is the variable that needed a transformation before use. We then grouped the cars by cylinder count and summarized fuel use and horsepower by their minimum, mean, and maximum.

cars |>
  mutate( `L/100km` = 235.215 / MPG ) |>
  group_by( Cylinders ) |>
  summarize( `Fuel Min` = min( `L/100km` ),
             `Fuel Mean` = mean( `L/100km` ),
             `Fuel Max` = max( `L/100km` ),
             `HP Min` = min( Horsepower ),
             `HP Mean` = mean( Horsepower ),
             `HP Max` = max( Horsepower ) ) -> by_cyl

Reporting values

thirsty <- format( max( by_cyl$`Fuel Mean` ), digits = 3 )
frugal  <- format( min( by_cyl$`Fuel Mean` ), digits = 3 )

Results

Mean fuel use rose steadily with cylinder count, from 9.05 L/100 km for the four-cylinder cars to 16.1 L/100 km for the eight-cylinder cars, and mean horsepower rose with it (Table 1).

by_cyl |>
  kable( digits = 1 ) |>
  kable_paper( "striped", full_width = FALSE ) |>
  add_header_above( c( " " = 1, "Fuel use (L/100km)" = 3, "Horsepower" = 3 ) )

Answers

Five of the six verbs return the same rows; one does not. summarize() is the exception. select(), filter(), arrange(), mutate(), and group_by() all hand back a data frame with the same rows they received (reordered, subset, or with columns added). summarize() collapses each group down to a single row of computed values, so the output has one row per group (or one row total with no grouping) rather than one row per original observation.

Deleting the group_by() line. The same summarize() call would return a single row: the minimum, mean, and maximum of fuel use and horsepower computed over all 32 cars at once. group_by() is what tells summarize() to run that calculation separately within each cylinder class and stack the results.
